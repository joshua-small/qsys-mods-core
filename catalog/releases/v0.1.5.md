Q-SYS Mods Core 0.1.5

Core now owns native and mod command bindings, configurable two-stroke chords,
context guards, and effective shortcut labels without requiring Better Shortcuts.
Existing native keys and saved assignments take precedence over conflicting mod
defaults. Competing defaults remain unassigned, and intentional overwrite uses
the shared review/apply flow.

Includes grouped native-command replacements, retired-command alias migration,
and a live settings.json interface for supported Q-SYS General preferences and
mod settings. Changes are validated, conflicts remain visible, and last-good
recovery data is preserved. Unsupported or unknown settings are not silently
treated as writable native preferences.

The merged source passed automated contracts and the scoped Designer 10.5
acceptance documented in docs/SETTINGS-JSON.md and docs/MOD-CONTROLS.md. Physical
floating-window and recorder acceptance retains its documented limits.

Requires the exact supported Designer 10.5 binaries and Q-SYS Mod Manager 0.8+.
Update old Better Packing/Better Shortcuts builds to 0.1.1 or newer when used
together. Existing mod preferences and user assignments are retained.
