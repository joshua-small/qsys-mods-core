Q-SYS Mods Core 0.1.6

Publishes the reviewed shared command, chord and live-settings implementation together with the subsequent floating-window, editor-input and native icon-menu fixes. This is a new immutable package; it does not replace the earlier public 0.1.5 package or locally tested 0.1.5 pins.

Core owns commands, default shortcuts, deterministic collision handling, effective bindings and validated live settings.json. Better Shortcuts is an optional editor. Existing custom bindings, unknown mod settings, native Preferences and last-good recovery retain their established preservation behavior.

Use Core 0.1.6 with Better Packing 0.2.0 and Better Shortcuts 0.2.0. Both feature packages require Core >=0.1.6 and <0.2.0. Existing compatible Core 0.1.x consumers retain their dependency range. Q-SYS Mod Manager 0.8+ and the exact supported Designer 10.5 build remain required.

Recorded acceptance covers the physical recorder/save, populated floating Component Controls, docked Monaco/Legacy editors, native property fields, F5/F6/F7 preservation and native editing icon hints/clicks in the documented US-layout scope. Detached Actipro hosts remain unsupported; additional native commands and contexts remain tracked separately. Native component Paste All is a Q-SYS defect tracked as support case 00404915, with the separate Clipboard Compatibility mod providing the temporary remedy. This packaging release adds no new Designer or hardware acceptance.
