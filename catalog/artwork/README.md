# Avitex artwork

These assets come unchanged from the owner-supplied `avitex-selected-identity-2026-10-13.zip`.
Both Schematic Tools and Automatic Geometry use this shared Avitex identity; the archive does not contain separate mod-specific logos.

- `avitex.ico` is the Mod Manager thumbnail. It includes the supplied 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 px frames, with optical adjustments at the smaller sizes.
- `avitex-256px.png` is the supplied raster brandmark for previews and other image consumers.
- `avitex-brandmark.svg` is the editable vector master for placements of 48 px and larger.
- `avitex-wordmark-blue.svg` is the outlined wordmark used in the repository README. It requires no installed font.
- `provenance.json` records the archive checksum, original entry names and SHA-256 of every copied asset.

The selected identity uses white artwork on signature blue `#0080ff`. No artwork was redrawn, recolored or rescaled for this repository.

The release publisher records the thumbnail's immutable source commit and SHA-256 in `qmm-catalog.json`. The approved catalog verifies them before publication. Future artwork changes belong in this repository and take effect in a subsequent release; published descriptors and historical assets remain unchanged.
